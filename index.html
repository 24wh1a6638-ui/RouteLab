DISTRIBUTED ROUTING

Distance Vector algorithm

Routers exchange distance information with their immediate neighbours and iteratively improve routes.

Bellman–Ford principle

How it works

  1. Each router starts with its direct-link costs.
  2. Routers share their distance vectors with neighbours.
  3. Each router checks whether a neighbour offers a cheaper route.
  4. Updates continue until no routing entry changes.

GLOBAL TOPOLOGY KNOWLEDGE

Link State algorithm

Each router builds a topology map and uses Dijkstra's algorithm to calculate shortest paths.

Dijkstra's algorithm

How it works

  1. Routers discover their directly connected neighbours.
  2. Link-state information is shared across the network.
  3. Each router builds a common topology database.
  4. Dijkstra selects the lowest-cost path from the source.
